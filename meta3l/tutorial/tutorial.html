meta3l tutorial

From an Excel sheet to three-level meta-analysis plots in four steps

Excel sheet→ meta3L()→ forest3L() · moderator3L() · loo_cluster3L()→ metabind3L()
1

Prepare packages

install once, load every session
# install once
install.packages("remotes")
remotes::install_github("vanioljantunes/meta3l",
                        subdir = "meta3l")

# load every session
library(meta3l)
meta3lfits the three-level model and draws the plots: meta3L() and the *3L() family
metaformodel engine (escalc, vcalc, rma.mv), installed with meta3l
clubSandwichcluster-robust CR2 confidence intervals
readxlreads every sheet of the Excel file

Every user function ends in 3L, so loading metafor or meta before or after meta3l never hides one of them. Updating meta3l in an open session? Run unloadNamespace("meta3l") before install_github(), then library(meta3l) again.

Read the workbook, pick the sheet

No file yet? The example below uses dat.bornmann2007 from the metadat package (installed with metafor): 66 odds ratios of women vs men being awarded a grant or fellowship, nested in 21 studies.

One row per effect size A study with left and right measurements, or several time points, has several rows with the same studlab. meta3l models that dependence; do not average the rows yourself.
Arm data, not effect sizes meta3l computes the effect sizes with escalc, so each row needs means, SDs and n (or events and n). Clean the data in the sheet, not in code.
3

One outcome: fit and plot

meta3L → forest, leave-one-out, funnel
# a. three-level model: effects nested in studies
r <- meta3L(d, slab = "studlab", measure = "OR",
            name = "fellowships",
            group.e = "Women", group.c = "Men")
r      # OR, 95% CI (CR2), I2 between / within

# b. forest plot, saved as fellowships_forest.png
forest3L(r)
forest3L(r, file = NULL)   # on screen instead

# c. sensitivity: drop one study / one effect
loo_cluster3L(r)
loo_effect3L(r)

# d. funnel + asymmetry test (10+ studies)
funnel3L(r)

4

Subgroups and several outcomes

moderator3L, bubble3L, metabind3L → summary forest
# all 66 awards, fellowships and grants
r_all <- meta3L(d_all, slab = "studlab", measure = "OR")

# subgroup: categorical moderator, Wald + LR test
moderator3L(r_all, subgroup = "type")
forest_subgroup3L(r_all, subgroup = "type")

# meta-regression: continuous moderator
bubble3L(r_all, mod = "year")

# one summary forest, broken down by type
mb <- metabind3L(`All awards` = r_all, subgroup = "type")
forest3L(mb, analysis.lab = "Analysis")

# several outcomes (regions, scales) in one figure
forest3L(metabind3L(Putamen = r_put, Caudate = r_cau))
Subgroup test moderator3L() fits one model with the subgroup as a moderator and shared variance components. In the summary forest, the p next to the analysis name is the test for subgroup differences.
Patients counted once The summary forest adds up patients per study without double counting left and right rows. If a study reports disjoint groups (neurological and hepatic, say), pass patients.by = "intervention" so both groups are counted.
Within-study correlationrho = 0.5
Assumed correlation between effect sizes of the same study, used by vcalc(). rho = 0 gives the plain three-level model most papers report. Say which one you used in the Methods.
Clustercluster = "studlab"
The column that defines level 3. Use a cohort or trial ID instead of the study label when several papers report the same patients.
Measuremeasure = "OR"
PLO, PAS (proportions), SMD, MD, RR, OR. Results come back on the natural scale: proportions as 0 to 1, ratios as ratios.
Saving plotsfile, format
Default file = NULL: the plot is drawn on screen and nothing is written. Give a path to save, or file = character(0) for a PNG named after name in getOption("meta3l.mwd"). format = "pdf" for vector output.
